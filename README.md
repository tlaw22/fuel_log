
# fuel_log

A new Flutter project.
This app is designed in flutter. Mostly vibe coded.
- It allows you to keep track of when you fill up your car and creates outputs monthly.
- It also includes a log page, delete function and a couple of graphs.
- There is a sync button in the top right that will allow you to sync data between two or more phones.
This feature is buggy but does work. If it freezes, lock your phones screen and try again in one minute. 
Our tests of this feature were done on to very different quality android phones.

- The graphs Android Auto output is in beta. This portion was coded in Kotlin for compatibility with android auto.
